# Лабораторная работа №2 — Трекинг объекта

**Цель:** отслеживать плоский объект по изображению первого кадра.

## 1. Теоретическая база

SIFT находит объект по локальным признакам, MAGSAC отбрасывает неверные соответствия. Гомография переносит четыре угла шаблона в текущий кадр. Между кадрами точки Shi–Tomasi отслеживаются пирамидальным LK с обратной проверкой и RANSAC. ECC уточняет положение относительно первого шаблона; локальная нормализация уменьшает влияние освещения.

## 2. Описание системы

`tracker.py` обрабатывает два фиксированных файла из `test-videos`: `mona-lisa.avi` и `video_2026-11-13_14-20-13.mp4`. `baseline_tracker.py` содержит первую версию для сравнения. Настроек запуска нет.

Нужны Python 3.10+, OpenCV, NumPy и FFmpeg в PATH.

```bash
pip install -r requirements.txt
python tracker.py
```

Цвет рамки текущего трекера:

| Цвет | Способ оценки |
| --- | --- |
| Зелёный | Первый кадр или независимый поиск SIFT с уточнением ECC |
| Голубой | Предыдущее положение / движение LK с уточнением ECC |
| Оранжевый | Движение LK без принятого уточнения ECC |

Жёлтые точки — набор Shi–Tomasi для следующего шага LK. В сравнении фиолетовая широкая рамка принадлежит первой версии. При потере рамка отсутствует. Интерполяции, подписей и дополнительной полосы нет; исходные размер и FPS сохраняются, звук не записывается.

## 4. Выводы

Пополнение точек и ECC уменьшают потери и дрейф. Сильное размытие и перекрытие могут приводить к отсутствию рамки; пропущенные положения не дорисовываются. Число кадров с рамкой не является измерением абсолютной точности.
